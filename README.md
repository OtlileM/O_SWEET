# O Sweets 
---

## 1. Project Overview
O Sweets is a sweet shop based in Pretoria selling colourful gummy sweets, mixed sweets and fruit flavoured sweets. 
Part 1 & 2 created a basic website with 5 pages (Home, About, Orders, Enquiry, Contact).
Part 3 enhances functionality with JavaScript, SEO, forms and deployment.

Storyline chosen: Small business - Sweet Shop (Product-based).
